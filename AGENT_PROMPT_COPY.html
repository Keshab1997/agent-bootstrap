ব্যবহারের নিয়ম

  1. Copy চেপে Notepad-এ paste → save (যেমন new-agent-prompt.txt)।
  2. নতুন agent-কে prompt-টা paste করে দিন, সাথে যে repo-তে কাজ হবে তার নাম বলুন।
  3. Agent pairing code দেখাবে → আপনি https://github.com/login/device এ approve করবেন → তারপর সে নিজে থেকেই কাজ শুরু করবে।
  4. সময় লাগে শুধু দুই জায়গায়: আপনার approval-এর অপেক্ষা, আর (Dart কাজ হলে) ৫০ সেকেন্ডের Flutter SDK। বাকি সব fast path-এ।
